DATABASE: baistock_db ENGINE: InnoDB (MySQL 8.0)

BaiStock Relational Database Architecture

10 Normalized Tables with Relational Constraints, Foreign Keys & Indexes

SAD Final Documentation Evidence 10 Tables • 100% Normalized
1. users Auth & RBAC
🔑 idBIGINT UNSIGNED (PK)
full_nameVARCHAR(100)
⚡ usernameVARCHAR(50) [UNIQUE]
⚡ emailVARCHAR(100) [UNIQUE]
passwordVARCHAR(255) [BCRYPT]
roleENUM(admin, owner, staff)
statusENUM(active, inactive)
created_at, updated_atDATETIME
2. products Inventory Items
🔑 idBIGINT UNSIGNED (PK)
🔗 category_idFK -> categories.id
product_nameVARCHAR(150) [INDEX]
priceDECIMAL(10,2)
quantityINT UNSIGNED [INDEX]
minimum_stockINT UNSIGNED
unit, image_pathVARCHAR(30, 255)
created_at, updated_atDATETIME
3. categories 5 Master Classes
🔑 idBIGINT UNSIGNED (PK)
⚡ category_nameVARCHAR(100) [UNIQUE]
descriptionTEXT
created_atDATETIME
4. sales POS Checkouts
🔑 idBIGINT UNSIGNED (PK)
⚡ receipt_numberVARCHAR(50) [UNIQUE]
🔗 user_idFK -> users.id
total_amountDECIMAL(10,2)
amount_receivedDECIMAL(10,2)
change_amountDECIMAL(10,2)
created_atDATETIME [INDEX]
5. sale_items Receipt Lines
🔑 idBIGINT UNSIGNED (PK)
🔗 sale_idFK -> sales.id [CASCADE]
🔗 product_idFK -> products.id
quantityINT UNSIGNED
unit_priceDECIMAL(10,2)
subtotalDECIMAL(10,2)
6. stock_movements Audit Log
🔑 idBIGINT UNSIGNED (PK)
🔗 product_idFK -> products.id
🔗 user_idFK -> users.id
movement_typeENUM(stock_in, out, sale, adj)
quantityINT UNSIGNED
remarksTEXT
🔗 sale_idFK -> sales.id
created_atDATETIME [INDEX]
7. deliveries Wholesale Shipments
🔑 idBIGINT UNSIGNED (PK)
⚡ tracking_numberVARCHAR(50) [UNIQUE]
supplierVARCHAR(255)
statusVARCHAR(50)
is_receivedTINYINT(1) (0/1)
total_costDECIMAL(10,2)
notesTEXT (Modal-only)
8. delivery_items Shipment Items
🔑 idBIGINT UNSIGNED (PK)
🔗 delivery_idFK -> deliveries.id
🔗 product_idFK -> products.id
quantityINT
unit_costDECIMAL(10,2)
subtotalDECIMAL(10,2)
9. notifications System Alerts
🔑 idINT (PK)
titleVARCHAR(255)
messageTEXT
typeVARCHAR(50)
action_url, action_textVARCHAR(255, 100)
is_readTINYINT(1)
created_atDATETIME
10. settings Key-Value Config
🔑 idBIGINT UNSIGNED (PK)
⚡ setting_keyVARCHAR(100) [UNIQUE]
setting_valueTEXT
updated_atDATETIME
